# 🐍 BlackViper OS

> A Debian-based cybersecurity learning environment created by VijayVinayak.

## 📖 About

BlackViper OS is a customized Debian Linux distribution designed for cybersecurity learning, system administration, programming, and Linux productivity.

This project is built by modifying Debian and integrating:

* Custom Python tools developed by me
* Custom Bash automation scripts
* Cybersecurity learning resources
* Linux utilities and frameworks
* Command memorization resources
* Red Team and Blue Team tool installers
* Productivity and development tools

The goal of BlackViper OS is to provide a ready-to-use environment for students and enthusiasts interested in Linux and cybersecurity.

---

## ⚡ Features

### 🔴 Red Team Installer

Run the desktop installer script and choose **Red Team** mode.

The script automatically installs selected security assessment and penetration testing tools.

### 🔵 Blue Team Installer

Run the desktop installer script and choose **Blue Team** mode.

The script automatically installs selected defensive and monitoring tools.

### 🐍 Custom Python Tools

Includes self-developed Python utilities for:

* Information gathering
* Automation
* Data processing
* Learning projects
* Security research

### 🐧 Linux Learning Resources

Built-in resources for learning:

* Linux commands
* Terminal navigation
* File management
* Networking basics
* System administration

### 🛠 Frameworks & Utilities

Various frameworks, utilities, and open-source tools are integrated to create a productive learning environment.

---

## 🚀 Getting Started

After booting BlackViper OS:

1. Open the Desktop.
2. Run the Team Setup script.
3. Select:

   * Red Team
   * Blue Team
4. Wait for the installation process to finish.
5. Start exploring the included tools and resources.
